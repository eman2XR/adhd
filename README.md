# A page for a friend

https://eman2xr.github.io/adhd/

An empty page that asks what it should be. Write what you want on it and how it should behave; it gets built, and you get a notification when the update is live. Once it has content, the button at the top ("What should this page do next?") opens the same box in a popup.

Getting set up on iPhone (the page shows these steps too):

1. Open your personal link in Safari.
2. Tap the Share button (on newer iPhones it is in the ... menu), then Add to Home Screen. If you see Open as Web App, leave it on. Tap Add.
3. Open the new icon on your Home Screen.
4. Tap "Notify me when it is live", then Allow.
5. Write what you want and tap Send.

On a Mac, open the link in Safari and tap "Notify me when it is live" directly.

How it works: see [CLAUDE.md](CLAUDE.md).
